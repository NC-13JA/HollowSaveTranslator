# Hollow Save Translator (Android)

محرر Android محلي لملفات حفظ Hollow Knight المتوافقة مع صيغة PC المدعومة.

## ما الذي تطور؟
- استعراض جميع القيم البدائية داخل JSON، وليس فقط الحقول التي تخمّن الأداة أنها موارد.
- فحص الكائنات والمصفوفات المتداخلة، مع مسارات واضحة لكل قيمة؛ وهذا يتيح الوصول إلى حقول المهارات والقدرات والأدوات والأسلحة والعناصر حتى عندما تكون أسماء الحقول داخلية.
- بحث بالاسم أو المسار أو النوع أو القيمة.
- تعديل الأرقام والنصوص والقيم المنطقية true/false.
- يدعم الوصول إلى العناصر داخل المصفوفات عند القراءة والتعديل.
- تصدير ملف معدل جديد، أو نسخة مطابقة من الملف الأصلي، دون الكتابة فوق المصدر.
- كل المعالجة تتم محليًا على الهاتف؛ لا يُرفع ملف الحفظ إلى خادم.

## حدود مهمة
- الصيغة المدعومة حاليًا هي ملفات PC التي تطابق الترويسة والتشفير المعروفين في المشروع. لا يُضمن دعم Switch أو جميع إصدارات اللعبة.
- يعرض التطبيق مفاتيح JSON الأصلية ومساراتها؛ لا يدّعي أنه يعرف المعنى البشري المؤكد لكل حقل. بعض الميزات تعتمد على عدة حقول مترابطة، لذا تعديل حقل منفرد قد لا يكفي أو قد يؤثر في تقدم اللعبة.
- إعادة بناء JSON قد تغيّر تنسيق النص الداخلي وترتيب بعض المفاتيح؛ لذلك يجب اختبار الملف الناتج على نسخة احتياطية، وليس على النسخة الوحيدة.
- لم يتم التحقق من كل حقل داخل اللعبة بعد. نجاح بناء APK لا يعني أن كل تعديل صالح داخل اللعبة.

## البناء
ادفع التغييرات إلى الفرع `main` أو شغّل GitHub Actions يدويًا. بعد نجاح workflow نزّل artifact باسم `HollowSaveTranslator-debug`.

## سلامة ملفات الحفظ
احتفظ بنسخة احتياطية خارج التطبيق. لا تستبدل ملف الحفظ الأصلي قبل التأكد من أن الملف المعدل يعمل بشكل صحيح.

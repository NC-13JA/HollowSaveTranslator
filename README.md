# Hollow Save Translator (Android)

مشروع Android أولي لقراءة ملف حفظ **Hollow Knight على PC** وتعديل بعض الحقول الرقمية التي يُحتمل أن تمثل Geo أو موارد أخرى، ثم تصدير ملف جديد دون الكتابة فوق الأصل.

## الحالة الحالية
- هذه نسخة أولية غير مختبرة على ملف حفظ حقيقي.
- لا يوجد APK مُتحقق منه حتى الآن؛ سيبني GitHub Actions نسخة debug عند push أو عند تشغيل workflow يدويًا.
- صيغة التشفير المعروفة هنا تخص ملفات PC التي تطابق الترويسة المستخدمة في المشروع. لا يُضمن دعم Switch أو جميع إصدارات اللعبة.
- أسماء الحقول التي يعرضها التطبيق مرشحة بالتخمين وليست قائمة مؤكدة بكل موارد اللعبة. راجع كل قيمة قبل التصدير.
- لا يدعم التطبيق حاليًا تحرير الأرقام الموجودة داخل المصفوفات JSON، ولا يُنصح باستخدام الملف المعدل على ملف الحفظ الوحيد لديك.

## البناء
افتح المشروع في Android Studio مع JDK 17 وAndroid SDK 35، أو ادفع التغييرات إلى الفرع `main` ثم افتح تبويب **Actions** ونزّل artifact باسم `HollowSaveTranslator-debug` بعد نجاح البناء.

## سلامة ملفات الحفظ
احتفظ بنسخة احتياطية خارج التطبيق، واختبر دائمًا على نسخة من الملف. لا توجد ضمانة أن إعادة تسلسل JSON ستحافظ على كل تفاصيل الملفات غير المعروفة.
